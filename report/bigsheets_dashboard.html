Bảng Đối Chiếu Kiến Trúc Nghiệp Vụ: BigSheets ⟷ Apache Spark

Mô tả chi tiết sự tương ứng giữa từng thao tác người dùng trên giao diện IBM BigSheets và cú pháp mã hóa phân tán của Apache Spark:

1. Nạp dữ liệu (Ingestion) New Collection
Định nghĩa nguồn dữ liệu HDFS và trích xuất cấu trúc cột.
spark.read.option("header", "true").schema(schema).csv(path)
2. Làm sạch (Cleansing) Add Sheet ➜ Filter
Lọc bỏ các bản ghi cảm biến đo âm, mất gói > 100%.
df.filter((col("latency_ms") >= 0) & (col("throughput_mbps") >= 0) & ...)
3. Cột tính toán (Calc Col) Add Sheet ➜ Formula
Tạo các cột nghiệp vụ tỷ lệ rớt mạng, nghẽn mạng và QoS.
df.withColumn("call_drop_rate_pct", when(...).otherwise(...))
4. Nối bảng (Dimension Join) Add Sheet ➜ Join
Nối bảng sự kiện đo kiểm với danh mục trạm BTS theo khóa ngoại.
df.join(df_towers, on="tower_id", how="inner")
5. Gom nhóm & Pivot (Group) Add Sheet ➜ Pivot / Group
Gom nhóm đa chiều theo Tỉnh, Công nghệ mạng và Trạm phát sóng.
df.groupBy("province", "technology", "tower_id").agg(...)
6. Sắp xếp thứ tự (Sorting) Toolbar ➜ Sort Z-A
Đưa các trạm có tỷ lệ rớt cuộc gọi và độ trễ cao nhất lên đầu.
df.orderBy(col("Mean_Call_Drop_Rate").desc(), col("Avg_Latency").desc())
7. Trực quan & Xuất báo cáo Charts & Export Feed
Xuất tệp CSV nạp vào Power BI và đồ thị hóa bằng Python.
df.write.csv("report/telecom_kpi_summary_powerbi.csv")

Mã Nguồn Thực Thi Apache Spark

# --------------------------------------------------------------------------
# SPARK DATAFRAME PIPELINE (Tương đương 6 bước IBM BigSheets)
# --------------------------------------------------------------------------
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, when, avg, count, round, desc

spark = SparkSession.builder.appName("BigSheets_Spark_Simulation").getOrCreate()

# 1. Collection -> DataFrame
df_events = spark.read.option("header", "true").schema(events_schema).csv("data/network_kpi_events.csv")
df_towers = spark.read.option("header", "true").csv("data/bts_towers.csv")

# 2. Filter -> filter / where (Loại bỏ 48 bản ghi âm hoặc lỗi cảm biến)
df_cleaned = df_events.filter(
    (col("latency_ms") >= 0.0) & (col("throughput_mbps") >= 0.0) &
    (col("packet_loss_pct") >= 0.0) & (col("packet_loss_pct") <= 100.0) &
    col("tower_id").isNotNull() & col("cell_id").isNotNull()
)

# 3. Calculated Columns -> withColumn
df_calc = df_cleaned \
    .withColumn("call_drop_rate_pct", when(col("call_dropped") == 1, 100.0).otherwise(0.0)) \
    .withColumn("congestion_status", when((col("num_active_users") > 150) & (col("throughput_mbps") < 15.0), "QUÁ_TẢI").otherwise("BÌNH_THƯỜNG")) \
    .withColumn("qos_score", round(100.0 - (0.35 * col("latency_ms") + 0.35 * col("packet_loss_pct") * 5.0 + 0.30 * col("call_dropped") * 50.0), 2))

# 4. Join -> join (Nối thông tin địa lý trạm phát sóng)
df_enriched = df_calc.join(df_towers, on="tower_id", how="inner")

# 5. Group -> groupBy & agg
df_kpi_summary = df_enriched.groupBy("province", "technology", "tower_id", "tower_name").agg(
    count("event_id").alias("Total_Sessions"),
    round(avg("throughput_mbps"), 2).alias("Avg_Throughput"),
    round(avg("latency_ms"), 2).alias("Avg_Latency"),
    round(avg("packet_loss_pct"), 2).alias("Avg_Packet_Loss"),
    round(avg("call_drop_rate_pct"), 2).alias("Mean_Call_Drop_Rate"),
    round(avg("qos_score"), 2).alias("Average_QoS_Score")
)

# 6. Sort -> orderBy
df_sorted = df_kpi_summary.orderBy(col("Mean_Call_Drop_Rate").desc(), col("Avg_Latency").desc())
df_sorted.show(10, truncate=False)
-- --------------------------------------------------------------------------
-- TRUY VẤN SPARK SQL TƯƠNG ĐƯƠNG (spark.sql)
-- --------------------------------------------------------------------------
SELECT 
    t.province,
    e.technology,
    e.tower_id,
    t.tower_name,
    COUNT(e.event_id) AS Total_Sessions,
    ROUND(AVG(e.throughput_mbps), 2) AS Avg_Throughput,
    ROUND(AVG(e.latency_ms), 2) AS Avg_Latency,
    ROUND(AVG(e.packet_loss_pct), 2) AS Avg_Packet_Loss,
    ROUND(AVG(CASE WHEN e.call_dropped = 1 THEN 100.0 ELSE 0.0 END), 2) AS Mean_Call_Drop_Rate,
    ROUND(AVG(100.0 - (0.35 * e.latency_ms + 0.35 * e.packet_loss_pct * 5.0 + 0.30 * e.call_dropped * 50.0)), 2) AS Average_QoS_Score
FROM network_events e
INNER JOIN bts_towers t ON e.tower_id = t.tower_id
WHERE e.latency_ms >= 0.0 
  AND e.throughput_mbps >= 0.0 
  AND e.packet_loss_pct <= 100.0
  AND e.tower_id IS NOT NULL
GROUP BY t.province, e.technology, e.tower_id, t.tower_name
ORDER BY Mean_Call_Drop_Rate DESC, Avg_Latency DESC;
